# Voix française

Clips de synthèse préproduits avec la voix **fr-FR-DeniseNeural** de Microsoft, via edge-tts, à un débit de -12 % et une hauteur de -2 Hz. Il s'agit d'une voix de synthèse, pas d'un enregistrement humain.

La génération est un outil de développement facultatif. Le jeu lit ces fichiers localement depuis son hébergement : aucun appel de synthèse et aucune clé API pendant les exercices.

Les syllabes ambiguës utilisent des mots homophones dans la source audio (`vo` → `veau`, `vai` → `vais`, `voi` → `voix`). Le texte de l'exercice garde son orthographe d'origine. Voir `src/pronunciation.js`.
